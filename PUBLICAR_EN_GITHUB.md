# Publicar Cuéntame mi cuento en GitHub Pages

Repositorio creado: https://github.com/jloptes-cmyk/cuentame_mi_cuento

1. Descomprime el ZIP en tu dispositivo (no subas el ZIP directamente a GitHub).
2. Abre el repositorio y pulsa **Add file → Upload files**. Si está vacío, también verás **uploading an existing file**.
3. Selecciona y sube TODOS los archivos **dentro** de la carpeta `cuentame-mi-cuento` directamente a la raíz del repositorio. Incluye `index.html`, `styles.css`, `app.js`, `stories.js`, `icon.svg`, `manifest.webmanifest`, `sw.js`, `README.md`, `.nojekyll` y esta guía. No subas la carpeta como subcarpeta.
4. Haz clic en **Commit changes**.
5. Abre **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**; selecciona `main` y `/(root)`, y guarda.
6. La web estará en https://jloptes-cmyk.github.io/cuentame_mi_cuento/ cuando termine la publicación.

IMPORTANTE: el cuento incluido es una adaptación PROVISIONAL para comprobar la personalización. Las ilustraciones también son provisionales.
